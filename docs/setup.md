## Project Setup Guide

1. **Clone the Repository**

   ```bash
   git clone https://github.com/smnthjm08/vercel
   ```

2. **Copy Environment Files**

   ```bash
   cp .env.example .env
   cd packages/db && cp .env.example .env
   ```

3. **Install Dependencies**

   ```bash
   bun install
   ```

4. **Start the Development Server**

   ```bash
   bun run dev
   ```

✅ **All set!** The app should now be running locally.
