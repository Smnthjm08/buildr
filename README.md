# 🧱 Buildrr

**Buildrr** is a full-stack deployment and hosting platform — inspired by platforms like Vercel — built to automate app deployments from GitHub repositories.

---

## 🚀 Tech Stack

- **Frontend:** Next.js (App Router) + Tailwind CSS + Shadcn UI
- **Backend:** Express.js + Node.js
- **Auth:** Better Auth (GitHub OAuth)
- **Database:** PostgreSQL with Prisma ORM
- **Queue & Workers:** Redis
- **Storage:** AWS S3 (for static build uploads)

---

## ⚙️ Core Features

- 🔐 Authentication with Better Auth (OAuth + Email Sign-in)
- 🧩 Organization & Workspace setup
- 🔗 GitHub Integration — import repositories directly
- ⚒️ Automated project creation & build deployment
- ☁️ AWS S3 static file hosting
- 📡 Redis-powered background workers
- 🧭 Clean, modular monorepo structure using Turborepo
